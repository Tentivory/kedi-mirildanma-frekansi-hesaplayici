# Kedi Mırıldanma Frekansı Hesaplayıcı

## Bu Proje Nedir?

Dünya tarihinin en önemli bilimsel başarılarından biri. Evrenin temel titreşimini oluşturan kedi mırıldanmalarının frekansını hesaplayan bu program, kuantum fizik, kedicilik ve varoluşsal krizlerin kesişim noktasında yer alır.

**UYARI:** Bu kodu çalıştırmak hayatınızı değiştirebilir. Kediler size farklı bakmaya başlayabilir.

## Nasıl Çalışır?

1. Python 3 yükleyin (veya yüklemeyin, yine de çalışır gibi yapar).
2. `python kedi_hesaplayici.py` komutunu çalıştırın.
3. Sonuçları ciddiyetle okuyun.
4. Kedinize anlatın.

## Özellikler

- Gerçek zamanlı sahte hesaplama
- Rastgele bilimsel görünümlü sayılar
- Mır mır ses efektleri (hayal edin)
- Evreni kurtarma potansiyeli (%0.001)
